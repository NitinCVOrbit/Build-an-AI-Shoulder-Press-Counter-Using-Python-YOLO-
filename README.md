# 🏋️ AI Shoulder Press Counter | YOLO Pose Estimation

Build your own **AI-powered Gym Trainer**! 🤖💪

This project uses **Python, OpenCV, and YOLO Pose Estimation** to detect human body movements, calculate joint angles, recognize shoulder press exercises, and automatically count repetitions in real time.

### 🎥 Watch the Full YouTube Tutorial
▶️ [Build an AI Shoulder Press Counter – Full Tutorial](https://youtu.be/Ug80WC9dQt0)

### ⚡ Key Features
- Real-time human pose detection
- Body keypoint tracking
- Automatic shoulder press repetition counting
- Joint angle calculation
- AI-powered exercise recognition

### 🛠️ Tech Stack
`Python` • `OpenCV` • `YOLO Pose` • `NumPy` • `Computer Vision`
